# Go-Proxy 究极矿池代理引擎 (商业级)

Go-Proxy 是一款采用纯 **Golang + Vue3** 打造的工业级加密货币矿池代理与算力中转引流系统。
它在网络底层深度重构了 Stratum 协议，拥有目前全网最先进的“完美拦截路由”机制与“平滑无感切池”技术，专为大算力矿场、大型工作室和集群化管理设计。

## 🚀 核心黑科技特性 (Elite Features)

### 1. 极致并发与极低延迟
- 基于 Golang 的 `net` 网络层与 `epoll` 异步 I/O，单台 4 核服务器可轻松承载 **10,000+ 台矿机**的并发连接。
- `sync.Pool` 内存池复用技术，内存占用恒定极低。

### 2. 完美拦截路由 (Stale Share Rescue) **【全网独家】**
彻底消灭切池重叠期引发的 `unknown job` 和拒绝率！
- 代理引擎内置基于 LRU 队列的 **Job Tracker**。
- 过目不忘，精准记忆矿池下发的所有 `JobID` 与以太坊 `Header Hash`。
- 切池交错瞬间交上来的 Share，代理从**物理层强制分拣**，将主池 Share 投递回主池，将抽水 Share 投递回抽水池。
- **影响**：实现真正的物理级 0 报错，挽回由于协议错位导致的算力蒸发，**100% 颗粒归仓**。

### 3. 平滑无感抽水引擎 (Transparent Switching)
- 切池时**绝不断开矿机连接**，ASIC 芯片无感过渡。
- 伪造新块下发指令欺骗矿机，矿机算力无需爬坡预热，全程 100% 满负荷。
- **微秒级算力打散**：支持将万台矿机的抽水时间打散到不同时段，主矿池显示的总体算力曲线如死水般平直，完美隐蔽。

### 4. 10秒抽水池续命机制 (Grace Period)
- 抽水结束切回主池时，原抽水网络连接会被插入“呼吸机”强行续命 10 秒。
- 保证矿机最后时刻算出的晚交（Late）抽水 Share 也能被成功路由并结算，榨干最后一滴油水。

### 5. 老矿机/傲娇矿池的终极杀器：自定义抽水周期
- 支持在每个端口单独设置**抽水大周期（分钟）**。
- 对付分配难度极慢的矿池，或老掉牙的不支持动态 Extranonce 的固件，可将周期设置为 `1440`（24小时）。
- 矿机在主池稳定运行 23.7 小时，一次性集中抽水十几分钟，极大摊薄了断线和预热造成的算力损耗。

### 6. 全协议覆盖
- 完美支持 **Stratum V1** 协议（BTC, LTC, BCH, KAS 等）。
- 深度重构支持 **Ethash / Etchash** 协议（ETHW, ETC, ZIL 等），精准抓取并提取 `eth_submitWork` 中的哈希指纹。

### 7. 高级管理与监控
- **赛博朋克深色仪表盘**：Vue3 + Vite 构建的丝滑前端，提供玻璃拟态视效。
- **实时日志监听**：无需敲命令，网页端 WebSocket 直推矿机通讯底层日志。
- **热重载技术**：修改参数保存瞬间生效，服务不断线。
- **多端口多币种**：单进程开启无数个监听端口，每个端口配置独立。

## 🛠️ 快速部署向导 (Linux 生产环境)

强烈推荐使用 Ubuntu 20.04/22.04 以获得最佳网络并发性能。

1. **下载一键提速安装脚本**
   ```bash
   wget https://raw.githubusercontent.com/yao52069/go-proxy/main/install.sh
   sudo bash install.sh
   ```
   *（注：此脚本会自动解除 Linux 系统的 `ulimit 65535` 并发封印，开启 TCP 快速重用，并为您配置好 Systemd 进程守护）*

2. **编译二进制文件**
   在您的开发机（Windows 或 Mac）上编译 Linux 版本：
   ```bash
   GOOS=linux GOARCH=amd64 go build -o proxy cmd/proxy/main.go
   ```
   然后将生成的 `proxy` 文件上传至服务器运行目录。

3. **启动引擎**
   ```bash
   chmod +x proxy
   systemctl start go-proxy
   ```

4. **登录控制面板**
   打开浏览器访问：`http://您的服务器IP:10010`

## ⚙️ 核心参数讲解

- **作者/运营者抽水比例**: 例如填 `1` 代表 1%。（支持两位小数，双层抽水机制）。
- **独立抽水矿池地址**: 强烈建议留空。留空则代理会自动复用主矿池网络（只替换钱包地址），确保获得与主池一致的超低延迟与 100% 稳定性。
- **算力全局虚标倍率**: 填 `1.2` 则矿工在面板看到的算力为实际的 1.2 倍。

针对中转 BTC（比特币，SHA256 算法） 和 LTC（莱特币，Scrypt 算法） 这种纯 ASIC 专业芯片矿机，为了配合我们刚才深度更新的 V2.0 商业级底层架构，以下是实现 0 损耗、100% 完美抽水的“满血版”最佳设定方案：

必开的核心选项（保底配置）：
✅ 专业ASIC芯片机增强支持：【必须打勾】

为什么必开：这正是我们刚才 V2 架构大更新的最核心武器！开启它后，引擎在切入抽水池时，会强制对蚂蚁/神马等矿机下发 clean_jobs=true 和专属的 ExtraNonce（扩展随机数）指令，并且全面激活 AsicBoost 算力解封。
后果：如果不勾选这个，BTC 和 LTC 矿机在抽水时会导致 100% 出现 "Job not found" 或 "Invalid Share" 被抽水池全部拒绝！
✅ 平滑无感抽水引擎：【保持打勾】

为什么必开：配合新架构的“时间切片强隔离”机制，它能把抽水时间打散成非常平滑的碎块。抽水矿池能稳定收到平滑算力，而主矿池的算力波谷会被完美抹平，极大降低被大矿池判定为作弊或拔线的概率。
进阶/可选选项（根据矿场情况调整）：
🔲 开启完美防封禁 (0拒绝率)：【强烈推荐打勾】

作用：如果您中转的是跨国海外大矿池（比如在大陆直连币安、蚂蚁池），高 Ping 延迟难免会产生个别 Stale (过期) 份额被矿池 Reject。勾选此项后，代理会替矿机把这些 Reject 拦截下来，并给矿机发送伪造的 Accept 成功信号。这能彻底防止矿机因为“拒绝率过高”而自动重启甚至掉算力。
🔲 开启 Auto-Vardiff 智能动态难度：【按需打勾】

情况 A（不建议开启）：如果您的矿场全是清一色的最新款高算力机器（比如全场蚂蚁 S21 / S19xp），建议不打勾，完全交给大矿池自身去分配难度，代理端可以节省出大量 CPU 性能用于并发。
情况 B（建议开启）：如果您的矿场是新老机器混杂（比如里面还混着古董级的 S9），为了防止低端老机器因为等不到合适难度的任务而频繁掉线，建议打勾，由代理端帮它智能降频。
🔲 开启微比特 (ViaBTC) 深度优化：

作用：仅仅当您的主矿池或者抽水池设置的是 微比特 (ViaBTC) 时，才需要开启。开启后能完美解决微比特特有的协议重复下发 Bug。如果挖的是别的池子，无需勾选。
下方的难度参数框怎么填？
对于 BTC 和 LTC 这类超高难度币种：

主矿池强制初始难度：建议留空（不干预，让 F2Pool/Antpool 去自动分配最适合您矿机的初始难度）。
抽水矿池强制初始难度：强烈建议填 auto。这样抽水瞬间，引擎会直接继承主矿池刚下发给矿机的最佳难度，实现毫秒级的无缝切换，连算力波纹都不会泛起一点！


- 针对 ETC 中转和抽水，策略会有所不同。以下是 ETC 的专属满血设定方案：

必开的核心选项：
✅ 平滑无感抽水引擎：【必须打勾】

原因：ETC 矿池（比如 F2Pool, Epool）对算力曲线波动的侦测非常敏感。如果不打平滑切片，直接硬切走几分钟，矿池的算力报表上会出现非常扎眼的“大锯齿”或“掉线”提示。开启平滑抽水后，代理会把抽水时间撕碎，完美抹平 ETC 矿池的曲线，做到肉眼绝对无感。
✅ 开启完美防封禁 (0拒绝率)：【强烈必须打勾】

原因：ETC 的出块速度极快（大约 15 秒一个区块，而 BTC 是 10 分钟）。这意味着在网络延迟稍高时，ETC 极易产生 Stale Share（过期份额 / 延迟拒绝）。
像 nbminer、lolminer 或部分 ETC 专属机（如 茉莉、芯动）对拒绝率非常敏感，一旦发现频繁被 Reject，它们可能就会疯狂重启 DAG 内存，导致算力暴跌。开启此项，代理直接把所有过期拒绝拦截，并对矿机伪造 Accept（接收成功）。矿机不仅不会重启，本地日志还会显示极其完美的 100% 成功率。
可选 / 无需关注的选项：
🔲 专业ASIC芯片机增强支持：【可开可不开】

原因：这个选项（强刷 ExtraNonce）主要针对 BTC 和 LTC。ETC 协议里压根没有这个概念，它只认普通的哈希值和随机数（Nonce）。我们更新的 V2 底层会自动识别出您连接的是 ETC 矿池，从而主动休眠这项功能。所以您打勾也无妨，引擎很聪明，知道对 ETC 不生效。
🔲 开启 Auto-Vardiff 智能动态难度：【不要打勾】

原因：ETC 的难度管理非常简单直接，矿池原生的分配机制已经足够完美，代理端画蛇添足去接管反而会增加显卡/矿机计算负担，直接留空让矿池自己管即可。
难度参数框怎么填？
同理：

主矿池强制初始难度：留空
抽水矿池强制初始难度：填 auto（ETC 的难度跨度很大，填 auto 直接克隆主矿池难度，防止抽水瞬间显卡算力卡死）。
总结： 跑 ETC 时，死死拿捏住 “平滑无感” 和 “0拒绝率（伪造成功）” 这两项，就能让您的 ETC 矿场如丝般顺滑，而且抽水极其隐蔽！
